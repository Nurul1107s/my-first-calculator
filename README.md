# my-first-calculator

My first Python project - a simple calculator built while learning to code.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## How to Run
1. Download `calculator.py`
2. Open with any Python app or run `python calculator.py`
3. Enter two numbers and choose an operation
